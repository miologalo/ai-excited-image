A rocket launching straight up through the curl of a giant ocean wave at
golden hour — seawater exploding outward in a crown of spray lit gold by the
low sun. One look, one thrilling moment: surprise (a rocket through a wave),
momentum (launch, spray bursting outward), and awe (the sheer scale of the
wave against the slender rocket). Clean, no text, reads at 300px.

## Entry

`main.py` (Python 3.13, standard library only) copies the bundled
`image.jpg` (1024x1024 JPEG, 360,320 bytes) to `/output/entry.png`,
validating the gate first: at most 1 MiB and at most 1024x1024 pixels.

Run it:

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```

Both runs write identical bytes.
